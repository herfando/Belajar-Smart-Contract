## 📚 Tentang Proyek Ini

Selamat datang di dunia Web3 dan Smart Contract! ✍️

Repositori ini adalah panduan praktis untuk Anda yang ingin menguasai pengembangan Smart Contract di blockchain Ethereum. Di sini, Anda akan menemukan:

- **Tutorial langkah demi langkah** untuk membangun dan menguji Smart Contract.
- **Contoh kode** yang dapat langsung digunakan dan dimodifikasi.
- **Tips dan trik** untuk mengoptimalkan pengembangan Smart Contract Anda.

---

## 🛠️ Teknologi yang Digunakan

| Teknologi     | Deskripsi                                      |
|---------------|------------------------------------------------|
| 🔹 Solidity   | Bahasa pemrograman utama untuk Smart Contract  |
| 🔹 Hardhat    | Framework untuk pengembangan dan pengujian     |
| 🔹 Ethers.js  | Library JavaScript untuk berinteraksi dengan Ethereum |
| 🔹 Chainlink  | Jaringan oracle terdesentralisasi              |

---

## 🚀 Cara Memulai

```bash
# Clone repositori ini
git clone https://github.com/herfando/Belajar-Smart-Contract.git
cd Belajar-Smart-Contract

# Install dependensi
npm install

# Compile kontrak
npx hardhat compile

# Jalankan tes
npx hardhat test

# Deploy ke jaringan lokal
npx hardhat run scripts/deploy.js --network localhost
